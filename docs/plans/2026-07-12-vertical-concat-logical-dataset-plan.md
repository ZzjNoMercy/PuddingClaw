# 垂直合并逻辑数据集实施计划

创建时间：2026-07-12  
状态：已完成

## 目标

把字段口径一致的周期性表格文件（如月度/周度销量、上险量）合并为一个可复用的**逻辑数据集**。它属于数据资产层，不属于资产关系：后续只需让这个逻辑数据集绑定一次车系、时间等维度。

## 第一性原则

- 原始表是事实来源，不能被合并操作覆盖或删除。
- 合并结果是显式、可刷新、可追溯的数据资产，而不是 Agent 临时 `concat`。
- 默认先预检字段集合。字段不一致时必须由用户确认后才物化：缺失字段补空值；用户选择保留额外字段或丢弃额外字段，绝不静默处理。
- 每一行保留来源资产、文件、Sheet 和虚拟路径，避免跨期数据无法审计。
- 合并后的逻辑资产拥有独立 Profile、字段列表和 `table_asset` ID，可进入模型、维度绑定和 Pandas 分析。

## 产物

```text
backend/data/analytics-concat-datasets/{asset_id}/dataset.parquet
knowledge_table_assets.source_type = derived_concat
knowledge_table_assets.asset_metadata.logical_dataset = {
  kind: vertical_concat,
  source_asset_ids: [...],
  schema_mode: strict | baseline_fill_missing | union_fill_missing,
  row_lineage_columns: [...],
  refreshed_at: ...
}
```

输出列为：规范后的原始业务字段 + `_pc_source_asset_id`、`_pc_source_file_name`、`_pc_source_sheet_name`、`_pc_source_virtual_path`。

## 操作流程

1. 在“数据资产”点击“合并表格”。
2. 输入逻辑数据集名称，勾选至少两张表格资产。
3. 后端按首张表定义基准字段顺序，预检所有来源并返回缺失/额外字段。
4. 字段一致时可直接创建；存在差异时用户选择策略：保留额外字段并以字段并集物化，或丢弃额外字段、仅保留基准表字段。两种方式都会将缺失的保留字段置空。
5. 成功后生成 Parquet、Profile 和新的逻辑数据资产。Parquet 写入前会统一推导字段类型，避免周期文件的 Excel/CSV 推断差异导致失败。
6. 后续点击“刷新合并数据集”时，按已登记来源重新物化；原始表更新后即可刷新。
7. 在资产关联中选择逻辑数据集，建立一次维度绑定；模型和 Agent 面对的是统一事实表。

## 任务清单

- [x] TableCatalog 支持创建、刷新、读取和 Profile 逻辑合并数据集。
- [x] Pandas 工具支持读取 Parquet 逻辑数据集。
- [x] Analytics API 暴露创建和刷新接口。
- [x] 数据资产 UI 支持选择表格、创建和刷新逻辑数据集。
- [x] 覆盖严格 schema、字段差异确认、缺失补空、行来源和刷新测试。
- [x] 创建弹窗内展示字段差异与 API 错误；全局提示提升至弹窗之上，避免错误被遮罩隐藏。
- [x] API 端到端覆盖字段一致、少字段、多字段保留、多字段丢弃与后续追加来源。
- [x] `build-logical-dataset` Skill：先列资产、再由 HITL 确认基准和策略，最后由受控工具创建或追加。

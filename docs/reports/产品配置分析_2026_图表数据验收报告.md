### 2.2 判定规则

- 天数、均值和分位数：按报告显示精度比较；不能以手工整数替代计算值。
- 交互图：任一可选状态错误，整张交互图不通过。
- “条件通过”：主图有效值正确，但缺少语义资产要求的未知项、字段覆盖率或样本量披露。
- 无法由物理字段证明的指标名称，不因数值接近而判为通过。

## 5. SQL 口径摘要

完整 SQL 文件包含 Q01–Q20，覆盖 24 张图表和核心配置模块的全部可选状态。以下为关键计算模式。

### 5.1 配置款型分母与标识

```sql
WITH models AS (
  SELECT DISTINCT launch_year, brand, serial_name, car_name
  FROM vehicle_model_base
  WHERE launch_year BETWEEN 2020 AND 2026
    AND vehicle_level IS DISTINCT FROM '皮卡'
), flags AS (
  SELECT brand, serial_name, car_name,
         BOOL_OR(type_name = '可调悬架种类'
                 AND type_value LIKE '%空气悬架%') AS equipped
  FROM vehicle_params
  GROUP BY brand, serial_name, car_name
)
SELECT launch_year,
       COUNT(*) AS eligible_count,
       COUNT(*) FILTER (WHERE equipped) AS equipped_count,
       ROUND(100.0 * COUNT(*) FILTER (WHERE equipped)
             / NULLIF(COUNT(*), 0), 2) AS config_rate_pct
FROM models m
LEFT JOIN flags f USING (brand, serial_name, car_name)
GROUP BY launch_year;
```

### 5.2 高压平台结构与披露率

```sql
COUNT(*) FILTER (WHERE voltage_band IS NOT NULL) AS disclosed_count,
ROUND(100.0 * COUNT(*) FILTER (WHERE voltage_band IS NOT NULL)
      / NULLIF(COUNT(*), 0), 2) AS disclosure_rate_pct,
ROUND(100.0 * COUNT(*) FILTER (WHERE voltage_band = '800V')
      / NULLIF(COUNT(*) FILTER (WHERE voltage_band IS NOT NULL), 0), 2)
  AS v800_composition_pct
```

平台值只识别语义资产指定的 `400V平台`、`800V平台`、`900V平台`/`897V平台`；内部结构分母是已披露平台的款型，披露率分母是全部新能源或纯电款型。

### 5.3 款型与车系独立计算

```sql
-- 款型配备率
COUNT(*) FILTER (WHERE equipped) / COUNT(*)

-- 车系覆盖率：先按 brand + serial_name 聚合，只要一个款型配备即覆盖
BOOL_OR(equipped) AS series_equipped
```

核心热力图的 3 个配置 × 3 个维度 × 2 种颗粒度共 18 个状态，均由 Q20 返回独立分子、分母和比率，没有复用矩阵。

## 6. 主要问题与修复优先级

### P0：阻断发布

1. 不要再由 2026 HTML 加载名为 `product-config-charts-2024.js` 的手工数据文件。
2. 用本报告 Q01–Q20 的结果生成唯一数据快照，并记录 `data_as_of`、SQL 版本和生成时间。
3. 删除所有示例矩阵、手工整数和 `value * 1.18 + 0.3` 外推逻辑。
4. 款型配备率与车系覆盖率必须分别聚合并分别写入 HTML 数据对象。

### P1：口径确认

1. 明确页面“L2+”是否等于物理字段 `L2 OR L2&L3`；若不是，需要新增语义映射。
2. 供应商份额图必须在标题或注释中声明时间范围与“组合供应商”归类规则。
3. 智驾芯片分类需确认 `Orin-X`、`Orin`、`EyeQ5H` 等同义值映射，再固化分类 CASE。

### P2：披露完整性

1. 轴距 100% 堆叠图增加“未知”或明确只在有效样本内归一化。
2. 电机功率、平台电压、屏幕尺寸等图表展示字段覆盖率或有效样本量。
3. 箱线图分别存储下须、Q1、中位数、Q3、上须、离群最高值，不能把绝对最小/最大直接当须线。

## 7. 最终验收意见

当前 HTML 可以作为视觉和交互模板继续使用，但**不能被认定为由 2026 数据真实刷新生成的分析报告**。完成 P0 修复、重新生成数据快照并再次执行同一 SQL 验收后，才建议进入业务验收。

# 高阶智驾配置率口径

## 适用目标配置

- 高阶智驾
- 高阶辅助驾驶
- 城市辅助驾驶
- 城区辅助驾驶
- 城市 NOA
- 城区 NOA

## 依赖语义资产

- 度量值：配置率
- 颗粒度：款型或车系

## 配置识别规则

高阶智驾必须使用 `城市辅助驾驶` 字段判断，不得通过辅助驾驶等级、
激光雷达、智驾芯片或其他相关配置反推。

权威识别条件：

- `type_name = '城市辅助驾驶'`
- `type_value` 明确表示标配或选装

标配和选装均视为已配置高阶智驾。

该字段在当前数据库中的配置状态编码为：

- `●`：标配，计入分子。
- `○`：选装，计入分子。
- `选配`：选装，计入分子。
- `-`：未配备，不计入分子。

兼容明确的文本状态 `标配` 和 `选装`。配置识别必须使用白名单：

```sql
vp.type_name = '城市辅助驾驶'
AND vp.type_value IN ('●', '○', '选配', '标配', '选装')
```

不得仅使用“非空且不等于 `-`”判断，因为未知的新值不能被静默算作已配置。
遇到白名单之外的新值时，应先返回取值分布并说明口径不确定性。

## 分子规则

在当前筛选范围和当前颗粒度内，命中上述配置识别规则的统计对象数量。

款型颗粒度：

- 按 `brand + serial_name + car_name` 去重。
- 同一款型存在多条 `城市辅助驾驶` 明细时，只计一次。
- 只要该款型的有效明细中存在“标配”或“选装”，即计入分子。

车系颗粒度：

- 先在款型层判断是否配置高阶智驾。
- 再按 `brand + serial_name` 去重。
- 同一车系至少有一个款型标配或选装城市辅助驾驶，即视为该车系覆盖高阶智驾。

## 分母规则

分母继承 `measure:config_rate` 和当前颗粒度资产的定义，本 reference 不重复定义。

分子必须继承分母的全部筛选条件，包括时间、能源类型、价格段、品牌、车系、
销售状态以及默认排除皮卡规则。

## 推荐聚合方式

款型层应先聚合配置标志，再计算配置率：

```sql
BOOL_OR(
  vp.type_name = '城市辅助驾驶'
  AND vp.type_value IN ('●', '○', '选配', '标配', '选装')
) AS has_high_level_adas
```

不得直接统计 `vehicle_params` 明细行数。

## 禁止规则

- 不得使用 `辅助驾驶等级 = 'L2'` 或 `L2+` 判断高阶智驾。
- 不得只统计标配而排除选装。
- 不得使用激光雷达、智驾芯片、算力或传感器数量反推高阶智驾。
- 不得仅根据用户输入的“高阶智驾”文字直接模糊匹配 `type_name`。
- 不得按单独的 `car_name` 去重；款型颗粒度必须使用
  `brand + serial_name + car_name`。
- 不得在本 reference 中重新定义配置率分母、上市时间或价格段口径。

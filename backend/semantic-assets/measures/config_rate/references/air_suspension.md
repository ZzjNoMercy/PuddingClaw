# 空气悬架配置率口径

## 适用目标配置

- 空气悬架
- 空悬
- 空气悬架搭载率
- 空气悬架配置率

## 依赖语义资产

- 度量值：配置率
- 维度：上市时间
- 维度：价格段

## 配置识别规则

空气悬架不是直接用 `type_name = '空气悬架'` 判断。

应使用：

- `type_name = '可调悬架种类'`
- `type_value` 包含 `空气悬架`

## 分子规则

在当前筛选范围和当前颗粒度内，命中上述配置识别规则的统计对象数量。

如果当前颗粒度是款型颗粒度，分子按 `car_name` 去重。

如果当前颗粒度是车系颗粒度，先在款型层判断是否搭载空气悬架，只要有某一款搭载，就算整个车系搭载。

## 分母规则

分母仍由 `配置率` 度量值和当前颗粒度定义，不在本 reference 中重复定义。

## 禁止规则

- 不要使用 `type_name = '空气悬架'` 作为识别条件。
- 不要在本 reference 中重复定义上市时间、价格段等维度字段口径。

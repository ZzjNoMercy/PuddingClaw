# 充电倍率

## 业务口径

充电倍率用于衡量快充过程中的平均充电速度。

本度量值计算的是平均快充倍率，不是峰值充电倍率。

## 计算公式

```text
充电倍率 C = 快充电量差值 / 快充时间（小时）
```

其中：

- 快充电量差值来自快充电量区间，例如 `20% - 80%`。
- 对 `20% - 80%`，差值为 `80% - 20% = 60% = 0.6`。
- 快充时间必须换算成小时，单位为 `h`。
- 结果单位为 `C`。

示例：

```text
快充时间 = 0.5 小时
快充电量 = 20% - 80%
快充电量差值 = 60% = 0.6
充电倍率 = 0.6 / 0.5 = 1.2C
```

## 字段口径

计算时需要读取：

- 快充电量区间，例如 `20% - 80%`。
- 快充时间。

如果数据库中快充时间使用分钟，应先转换为小时：

```text
小时 = 分钟 / 60
```

## SQL / 数据处理要求

快充电量通常是百分比区间文本，需要解析区间上下限，再计算差值。

处理步骤：

1. 从快充电量字段中提取两个百分比数字。
2. 用较大值减较小值，得到百分比差值。
3. 将百分比差值除以 100，得到小数形式。
4. 将快充时间转换成小时。
5. 用小数差值除以快充时间，得到平均充电倍率。

## 禁止规则

- 数据库中即使存在 `type_name = '电池充电倍率'`，也禁止直接使用该字段的值作为答案。
- 充电倍率必须通过快充电量区间和快充时间按公式计算得到。
- 不要把 `60%` 当成数值 `60` 直接除以小时，应先转换成 `0.6`。
- 不要把分钟单位当作小时使用。
- 不要把本度量值解释为峰值充电倍率。
